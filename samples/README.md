# Sample files

Dummy files (not real game data) — just so you can see the four file icons after installing:

- `sample.pkg` / `sample.exfat` / `sample.ffpfsc` / `sample.ffpkg`

Openable demo: `Loopayeh-Sample/` is a minimal PS5 app folder
(`sce_sys/param.json` + white-logo `icon0.png`) — drop it on the app
and it loads like a real game, showing the Loopayeh logo as cover.
